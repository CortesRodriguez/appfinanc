# Diagrama de componentes — appfint

El diagrama de componentes de la Fase 4 se encuentra en:

**[`docs/diseno/04_diagrama_componentes.md`](../../diseno/04_diagrama_componentes.md)**

Ese archivo contiene:

- El bloque **PlantUML** completo con el diagrama (actor, interfaces ball-and-socket, componentes con estereotipos de arquitectura/negocio coloreados en ámbar y púrpura).
- **Responsabilidades por componente** — qué hace cada uno.
- **Dependencias** — qué transporta cada línea.
- **Trazabilidad** — mapeo componente ↔ archivo Python real.
- **Reglas de dependencia** — el contrato de diseño en prosa.
- **Deuda arquitectónica** — inconsistencias documentadas entre las reglas y el código actual.

Este archivo se conserva solo como puntero: la fuente canónica del diagrama es el de la carpeta `docs/diseno/`.
